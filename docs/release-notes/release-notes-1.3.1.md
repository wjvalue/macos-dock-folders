# v1.3.1 — 五个体验修复

全是用下来的实际反馈，一个 .app 修五个不顺手的地方：

## 修了什么

1. **换了图标风格，Dock 上不刷新（要点一下才变）**
   根因在系统：Dock 按 icns 的「文件路径」缓存图标，内容换了名字没换就不刷。
   现在图标一变，icns 就换成带内容摘要的新文件名，**apply 完立即生效**。

2. **每次「应用到 Dock」，手动拖的分组顺序被弹回原位**
   已在 Dock 上的分组现在**原地替换**——你拖到哪就是哪。配置里的 `after`
   锚点只在分组**首次落位**时生效；想让某分组重新按 `after` 落位：
   `dg remove <组名>` 再 `dg apply`。

3. **每次点「应用到 Dock」都全屏闪一下**
   有变更时这一下免不了（Dock 只能整体重启）；但配置没变时会**跳过重启**，
   连点两下只有第一下会闪。

4. **管理窗口改外观永远改的是全局**
   右栏新增「当前分组 / 全局默认」范围开关：默认只改左边选中的分组，
   想动全局再切过去。引擎侧同时补上了分组级风格覆盖的支持。

5. **成员卡片上的移除减号看着像被遮住**
   那个减号是「挖空」符号，透出的是底下 App 图标的颜色。重画成
   红圆 + 实心白减号，不再挑背景。

## 升级

- 老用户：重新下载解压，**双击即升级**（幂等重装）；或跑 `install.command`。
- 升级后第一次 `dg apply` 会自动重建图标缓存（新版 icns 文件名触发），不用手动处理。
